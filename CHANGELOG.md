# История версий

## 0.2.2

- Поддерживаются все пять значений `LoopMode` из KANALI 2.7.0, включая последовательное и случайное воспроизведение пресетов. Регулировка яркости и переключение подсветки сохраняют выбранный режим.

## 0.2.1

- Исправлена блокировка управления, когда KANALI записывает режим повтора всех медиа как `LoopMode_MediaAll`. При изменении подсветки и яркости режим воспроизведения сохраняется.
- При неизвестном значении перечисления диагностика показывает полученную метку. Управление остаётся заблокированным до успешной проверки конфигурации.

## 0.2.0

- Обнаружение девяти USB ID семейства TRYX Panorama и явный выбор экрана при нескольких подключениях.
- Проверка DeviceInfo и конфигурации перед управлением. Для экспериментальных профилей автоуправление включается отдельно для каждого экземпляра.
- Диагностика показывает обнаруженный USB ID, доступность USBPRINT и результаты чтения. При отключении выбранного экрана автоматического перехода на другой нет.
- Новые профили проверены на имитации. Подтверждённая на оборудовании комбинация остаётся TRYX Panorama `391A:1011` с KANALI 2.7.0.

## 0.1.0

Первая версия, подготовленная для публичного релиза. Программа автоматически выключает подсветку TRYX Panorama при простое и включает её при возвращении пользователя.

- Тайм-аут от 1 до 1440 минут и синхронизация со временем отключения дисплея Windows.
- Ручное включение и выключение подсветки, пауза и управление из трея.
- Регулировка яркости от 0 до 100% и диагностика экрана с подтверждением через журнал UDB.
- Автозагрузка, запуск свёрнутым, восемь языков и системная, светлая или тёмная тема.
- Автономная сборка для Windows x64 и деморежим для проверки без устройства.
- Документация на восьми языках. Исходный код и документация доступны под [CC0 1.0 Universal](LICENSE).

**Проверено на TRYX Panorama `391A:1011` с KANALI 2.7.0.**

Версия релиза совпадает с `Version` в [проекте](PanoramaScreenMonitor.csproj) и Git-тегом вида `v0.1.0`. После публикации исправления и новые возможности получают новый номер версии.
