# Panorama Screen Monitor

**Русский** · [English](docs/i18n/README.en.md) · [Deutsch](docs/i18n/README.de.md) · [Français](docs/i18n/README.fr.md) · [Español](docs/i18n/README.es.md) · [Português (Brasil)](docs/i18n/README.pt-BR.md) · [简体中文](docs/i18n/README.zh-CN.md) · [日本語](docs/i18n/README.ja.md)

**Автоматическое управление подсветкой экрана СЖО TRYX Panorama в Windows.**

Экран Panorama может продолжать светиться, когда вы отошли от компьютера и основной монитор уже погас. Panorama Screen Monitor работает в трее, выключает подсветку СЖО после простоя и включает её при возвращении к компьютеру.

**Проверено на TRYX Panorama (USB ID `391A:1011`) с KANALI 2.7.0.** Для других моделей Panorama предусмотрена [экспериментальная совместимость](#совместимость-usb).

Около полугода назад я попросил разработчиков KANALI добавить автоматическое отключение подсветки при простое. К моменту подготовки этого релиза функция так и не появилась, поэтому я написал эту утилиту.

## Быстрый старт

**Требования:** Windows x64, TRYX Panorama из [таблицы совместимости](#совместимость-usb) и штатно запущенный KANALI.

1. Откройте [последний релиз](https://github.com/Viper029GH/PanoramaScreenMonitor/releases/latest) и скачайте EXE или ZIP для Windows x64. Если скачали ZIP, распакуйте его в удобную папку.
2. Запустите EXE. Установка и отдельная среда .NET не нужны. Если KANALI запустится позже, Panorama Screen Monitor дождётся его автоматически.
3. По умолчанию подсветка гаснет через **10 минут** простоя. Чтобы использовать время отключения основного монитора, раскройте **Настройки**, включите **Использовать тайм-аут экрана Windows** и нажмите **Сохранить**.

Крестик сворачивает программу в трей. Чтобы закрыть её полностью, выберите **Выйти** в меню значка. Если у вас уже работает скрипт управления подсветкой Panorama, остановите его перед запуском программы.

Сборка без цифровой подписи. Контрольные суммы файлов релиза указаны в `SHA256SUMS.txt`.

## Что умеет программа

| Возможность | Как работает |
| --- | --- |
| Автоматическое управление | Собственный тайм-аут от 1 до 1440 минут или настройка отключения дисплея Windows. Учитывается питание от сети или батареи. При значении «Никогда» подсветка автоматически не гаснет. |
| Ручное управление и пауза | Экран можно включить или выключить вручную из окна и трея. Пауза удерживает текущее состояние. Автоуправление можно возобновить в любой момент. |

| Диагностика | Модель, прошивка, ПО и ОС экрана, статус USB и UDB, яркость и время последнего успешного чтения. |

## Совместимость USB

**Проверено на TRYX Panorama (USB ID `391A:1011`) с KANALI 2.7.0.** Для остальных моделей из таблицы поддержка экспериментальная. Она рассчитана на устройства со штатным Windows-драйвером USBPRINT, теми же USB-командами и ответами в журнале UDB. На этих моделях работа пока не подтверждена на физическом устройстве. Если проверка чтения не проходит, управление экраном недоступно.

| USB ID | Профиль | Проверка в Windows |
| --- | --- | --- |
| `391A:1011` | Panorama | Проверено с KANALI 2.7.0 |
| `391A:1021`, `391A:1061` | Panorama SE | Экспериментально |
| `391A:1031`, `391A:10A1` | Panorama WB | Экспериментально |
| `391A:1071` | Panorama SE V2 | Экспериментально |
| `391A:1081` | Panorama V2 | Экспериментально |
| `391A:10B1` | Вариант Panorama | Экспериментально |
| `391A:1091` | Panorama WB V2 | Экспериментально |

Если подключено несколько экранов, выберите нужный в **Настройках**. При отключении выбранного экрана программа ждёт его или нового явного выбора. Для экспериментальной модели после успешного чтения доступны ручные команды. Чтобы включить автоматическое управление для этого экземпляра, нажмите **Разрешить автоуправление**.

В отчёте о совместимости укажите USB ID, прошивку, версию KANALI и результат чтения, ручных ON/OFF и изменения яркости. USB ID и прошивка видны в диагностике. Серийный номер для отчёта не нужен.

## Как это работает

Программа определяет простой по последнему вводу в Windows. Подсветка меняется через штатный USB-интерфейс устройства с общим доступом. KANALI продолжает работать, а Panorama Screen Monitor ищет ответ на собственный запрос в журнале UDB и проверяет фактическое состояние экрана. Для изменения яркости или подсветки программа читает свежую конфигурацию и сохраняет остальные поля. Если полная конфигурация не распознана, запись отменяется.

Синхронизация использует время отключения дисплея из схемы питания Windows. Воспроизведение видео, ручное отключение монитора и другие причины изменения состояния основного экрана могут влиять на него отдельно.

Настройки и небольшой диагностический журнал хранятся в `%LOCALAPPDATA%\PanoramaScreenMonitor`. При сообщении о проблеме укажите версию KANALI, версию прошивки из карточки диагностики и шаги для воспроизведения.

## Сборка из исходников

На компьютере для сборки понадобится **.NET 10 SDK**. Проект написан на C# и WPF.

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -o artifacts/publish/win-x64
.\artifacts\publish\win-x64\PanoramaScreenMonitor.exe --demo
```

В деморежиме можно попробовать интерфейс и смоделировать простой, ввод, ошибки и тайм-ауты без подключённой СЖО. Команда `PanoramaScreenMonitor.exe --self-test "<путь к отчёту>"` запускает встроенные проверки протокола, журнала UDB и контроллера на имитации.

Чтобы собрать материалы для GitHub Release, запустите `./scripts/build-release.ps1` из корня проекта в PowerShell. [Скрипт](scripts/build-release.ps1) проверяет сборку и помещает EXE, ZIP, уведомления о встроенной среде .NET и контрольные суммы SHA-256 в `artifacts/releases/`. Номер версии задаётся в [файле проекта](PanoramaScreenMonitor.csproj).

При разработке использована открытая документация формата команд и полей устройства. [Схема транспорта TRYX](https://github.com/DXVSI/Tryx-Linux-GUI/blob/production/protocol/wire-v1/transport.proto) · [Схема конфигурации](https://github.com/DXVSI/Tryx-Linux-GUI/blob/production/protocol/wire-v1/configuration.proto)

Для перечня кандидатов использованы профили TRYX Linux GUI, каталог USB-устройств и таблица сопоставлений KANALI 2.7.0. [Профили TRYX Linux GUI](https://github.com/DXVSI/Tryx-Linux-GUI/blob/production/src/printerproductprofile.cpp) · [Каталог Nexus](https://hellonexus.com/devices)
